# 工具接入

SnowLLM 提供兼容 OpenAI 和 Anthropic 的推理接口，也可通过适配层为 MinerU 提供模型推理。

| 接入方式 | 用途 |
| --- | --- |
| [pi.dev](../integrations/pi) | 将模型目录写入 Pi 的配置 |
| [HTTP API](../integrations/http-api) | Chat Completions、Responses、Messages 及 SnowLLM 扩展接口 |
| [MinerU](../integrations/mineru) | 使用原生文档解析流程，连接 SnowLLM 模型服务 |
