Web UI

    

      
No commands to memorize.

      
snowllm webui

      
Download models, chat and monitor inference in your browser. Web UI guide ↗

    

  



  

    
Integrations

    

      
snowllm pi --port 8000

      
Automatically generates ~/.pi/agent/models.json for pi.dev.

      
Other tools connect through APIs compatible with OpenAI and Anthropic. Integration guide ↗

snowllm qwen3.8-flash-next-iq4-xs-ud3.1
